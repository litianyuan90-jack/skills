# 《二十四节气》史实与出处

成片里出现的每个数字、引文都能在这里找到依据。存疑处标"一说"，约数写"前后"。

## 天文

| 项 | 内容 | 说明 |
|---|---|---|
| 一周 | 太阳在黄道上一年走 360° | 视运动；本片以地球公转呈现 |
| 一气 | 每 15° 一个节气，共 24 个 | 清《时宪历》（1645）起用"定气"，按太阳黄经等分；此前多用"平气"按时间等分 |
| 黄经零点 | 春分 = 0°，夏至 90°，秋分 180°，冬至 270°，立春 315° | 现行国家标准 GB/T 33661-2017《农历的编算和颁行》 |
| 黄赤交角 | 23.44°（23°26′） | 回归线纬度 |
| 太阳直射纬度 | δ = arcsin(sin 23.44° · sin λ) | 片中 HUD 数值由此公式算出：立春 南纬 16.3°，夏至 北纬 23.4°，冬至 南纬 23.4°，白露 北纬 5.9° 等 |
| 公历日期 | 均为"前后"，每年可差 1–2 天 | 立春 2月4日前后 … 大寒 1月20日前后 |

注：片中地球、太阳的大小与距离不按比例，轨道画成正圆（实际偏心率约 0.017）。

## 历史

- **《淮南子·天文训》**：西汉淮南王刘安主持编撰，最早完整记载二十四节气，名称、顺序与今相同。来源：[人民论坛网](https://www.rmlt.com.cn/2025/0710/734964.shtml)、[中国非物质文化遗产网](https://www.ihchina.cn/solarzx_details/25587.html)
- **列入人类非遗**：2016年11月30日，在亚的斯亚贝巴举行的联合国教科文组织保护非物质文化遗产政府间委员会第十一届常会上，"二十四节气——中国人通过观察太阳周年运动而形成的时间知识体系及其实践"列入人类非物质文化遗产代表作名录。来源：[中国非物质文化遗产网](https://www.ihchina.cn/project_details/10161.html)、[浙江在线](https://china.zjol.com.cn/gnxw/201612/t20161201_2138710.shtml)
- 旁白"两千多年前"：《淮南子》成书于约公元前 139 年，距今约 2160 年。
- **卷首题辞**：《黄帝内经·素问·四气调神大论》"春三月，此谓发陈""夏三月，此谓蕃秀""秋三月，此谓容平""冬三月，此谓闭藏"。

## 七十二候与释义

三候据《逸周书·时训解》《月令七十二候集解》（元·吴澄）。旁白里的释义：
- 立夏"万物至此皆长大"：《集解》"夏，假也，物至此时皆假大也"
- 小满：《集解》"物至于此小得盈满"
- 芒种：《集解》"谓有芒之种谷可稼种矣"
- 处暑：《集解》"处，止也，暑气至此而止矣"
- 白露：《集解》"阴气渐重，露凝而白也"
- 霜降：《集解》"气肃而凝，露结为霜矣"
- 大雪：《集解》"大者，盛也，至此而雪盛矣"
- "腐草为萤""雀入大水为蛤"等是古人的物候观察与附会，片中按原文呈现，不代表现代生物学。
